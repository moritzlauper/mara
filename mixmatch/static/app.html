Set up the connection

1. Install the MARA connection in your Ableton User Library.

2. Restart Live. In Settings → Link/Tempo/MIDI, select the control surface MixMatch (input/output: None).

3. Back in MARA, choose “Set taps”. The measurement devices require Max for Live.
